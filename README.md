# offline-archive-source

Source-code requests for the offline-archive library cards.

Every card carries a GPL written offer that names this repository. Most of the source is already on the card,
under `/library/source/`, with the licences page at `/library/licences/`. For anything else the offer covers:

1. Open an issue here.
2. Give the card's build ID, from its label or its licences page (it looks like `oa-20261107-02-127eb35`).
3. Name the package or program you want the source for, if you know it.

You will get a copy of the corresponding source, or a link to it, for no more than the cost of making and sending
the copy. The offer stands for at least three years from the date the card's library was sealed.
